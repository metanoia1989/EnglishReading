# 用 json 存文档
我不喜欢这种架构，文章都塞到 数据库里不是一个好的实现。
能不能 文章以文件形式存储，数据库里只存轻量数据。
文章已 json 格式文件存储，一个数据集就是一个目录，article 存 ID,标题,level,published_at, author, origin, relative_path, created_at
relative_path 放 相对路径 假设所有数据集放到 data 目录下，那么 数据集文件夹/日期（如果有的话）/文章文件名（清洗后的json）
这样如何？


文件需要建立hash，文件一旦发布就不能重清洗。今天导入器会拒绝"文本已变"的文章，正是这个原因；改成文件后，改文件比改 JSON 容易得多，违规成本也更高。所以必须加护栏，库里存 content_hash（文章级 sha256）。

现在批注锚点是 paragraph_id + sentence_index + word_index。paragraph_id 是数据库自增 id。正文一旦搬到文件，段落就没有 id 了，锚点必须换成 article_id + paragraph_index + sentence_index + word_index。
